https://gidp.dev/extensions/gidp/0.1

This URI identifies the Graduated Interest Disclosure Protocol, version 0.1, when it is declared as an extension in an A2A Agent Card (capabilities.extensions[].uri).

GIDP 0.1 does not define the A2A binding. Section 22.2 of the specification sketches it and uses this URI as its example; the reference implementation carries a worked mapping in impl/gidp/bindings/a2a.py. Until a binding is published, this is the URI that mapping uses.
